A run repeats these steps until it is blocked: by an approval gate, by nothing admissible, by its
step budget, or by an action no effect port performs. `run_until_blocked` in
`b10x-loom-commission` is that loop.

## 1. Project the catalogue — Loom

The frontier's admissible actions are projected into the catalogue the model can see. Nothing
consequential is offered because it was registered at startup; what the model sees comes from the
current frontier, which the governor computes with Canon for the case's current revision.

## 2. Select one action — Loom

A selector picks one action from that catalogue. It can be a model (the slice's `ModelSelector`, one
forced tool call), a deterministic rule, or, later, a fast typed selector. It chooses only from the
candidates it was given; Loom refuses any other. See [action selection](./action-selection.md).

## 3. Generate arguments for that action only — Loom

The argument generator is handed the selected catalogue entry and nothing else. Loom records the
request for arguments against the selection it serves, then returns the action as a
`ProposedAction`.

Since 0.3.0, the local slice can resolve [stored-result references](./result-references.md)
while generating those arguments. Only the expanded ordinary arguments reach the proposal and
subsequent admission; a reference never grants permission.

## 4. Revalidate — Commission runtime

Time passes between selection and effect: the case may have moved, and authority may have changed.
The runtime turns the proposal into an action request bound to the frontier's revision and
revalidates it against the current frontier, case revision and authority provider. An action that
needs approval the provider does not give stops the run.

## 5. Invoke the effect — Commission runtime

The runtime hands the admitted request to the `EffectPort` once and records what happened as an
observation, never as evidence. The case moves to a new revision only after an effect the port
reports as `Performed`. Loom does not make this call; see [where Loom ends](./where-loom-ends.md).

**5. Attacked and not broken**
- A failed turn, a panicking turn (sync or async) and a dropped future are each one call with cost absent.
- Retries through `send_with_retries` (intake and plugin) run on the thread that drives the turn, so each attempt is counted in its step.
- On the chooser path, selection and argument turns land on the step that made them.
- Cost is absent, never zero, for: no card, an unlisted model, a provider-reported model the card doesn't list, a non-final usage, and a usage missing input or output tokens.
- Each turn is rounded once, and the step and run totals are sums of rounded turns.
- The two rate cards have the same fields, validation and formula (`harness/turn_loop/price.rs:202-224` against `metering.rs:238-257`).
- The harness adapter needs `M: ModelPort`, which no llm-only host type meets, so nothing changes for a host that never uses the harness port.
- The story's two grep checks pass.
- `ReasoningModel` selection records now carrying 0 tokens is stated in `docs/contracts/loom-action-selection.md:123`, and no other document claims they carry tokens.

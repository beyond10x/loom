**5. Attacked, held**
- **New session id per call, no nil UUID:** a new `SessionId` per call, the real `commission_id`/`frontier_id`.
- **Proposal shape:** arguments are `{files}` only, a deletion is `content: null`, the summary and digest are not in the arguments and not in evidence, an empty session proposes `files: []`, and a failed session is `ExternalAvailability` when no cost limit is set.
- **Idle identity:** identical when only the summary differs, and paths are sorted so file order cannot vary.
- **`--restricted`:** every Claude session gets it, whether the runner is supplied, named or the default spawn (the named-program path is code-read only).
- **Paths out of the copy:** a symlink the session leaves makes the session fail, and a top-level `.git` is never proposed.
- **Scratch copy:** removed on drop. The workspace is only read before the effect runs.
- **SDK surface:** the CHANGELOG has the `**Breaking:**` bullet for `ExecutorStep`. `host_ports.rs` and the stability page list `loom_sdk::session`. `cargo tree --locked -i metaharness --depth 1` shows only `b10x-loom-session-executor`. Without `--depth`, `b10x-loom-conformance` also appears as a direct dependent (publish=false); I did not raise it.
- **Binary content:** content that is not UTF-8 is refused. A NUL-only file is valid UTF-8 and is proposed, which matches what the session domain states.

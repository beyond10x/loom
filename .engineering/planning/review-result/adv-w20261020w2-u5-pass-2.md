## 5. Attacked and could not break
- **`check_host` (by reading):** strict IPv4 parsing rejects shorthand, octal, hex and decimal forms, and a last label of all digits is refused. Only `[A-Za-z0-9-.]` reaches `/etc/hosts`. - **Byte-ceiling rule (by reading):** a result needs both the refusal code and the record's `max_bytes`. The unit test's negative cases catch a mutant that drops either clause.

## Findings

- runtime-wrapper (fixed in 93e0928c): `sdk-stability.md`'s `Runtime` row did not list
  `runs_mut` and `context_mut`. The six adversary cases (every context field, host stop, deadline,
  a second run, a resume after a run that held nothing, two Runtimes on one suspension store)
  held.
- session-executor-from-spec (fixed in 6f300361): a Claude Code or Codex spec under `frame` or
  `observe` built an executor whose allow list Loom did not enforce (no frame, so every call
  abstained and the copy check was skipped); a b10x-harness spec under `ask` built an executor
  metaharness refuses on every session; an allowed entry holding `,` was joined unescaped into
  `--tools`, offering a denied tool. `from_spec` now builds only under `ask` (Claude Code, Codex)
  or `observe` with the default policy (b10x-harness), and refuses a tool name holding `,` or
  whitespace (`SpecError`). The coordinator authorized one change to an adversary case: it accepts
  a refused spec, as the other three do.
- substrate-0-8-pin (fixed in e34da666): a single-aperture record naming a `listen` address was
  accepted as applied; `check_record` never compared the record's capsule or filesystem with the
  request. AGENTS.md now says Substrate 0.10.0 binds read-only roots through the descriptor its
  admission opened.
- stability-version-rule (fixed in 59b27ab0): a removal led by its verb, every item after the
  verb, a removed module of a listed path, a listed path gone under `renamed` or `moves to`, a
  deprecation led by its verb and a deprecated module were each misread; a span a removal only
  mentions, and a span the page leaves outside the promise, counted as removed.

## Notes not made into tests

- `SessionExecutor::tools` is a public field: a host that sets it without `from_spec` can still
  run Claude Code or Codex under `frame` or `observe`. `new` was left unchanged by design.
- `Runtime` takes only sized parts; judged not a defect.
- Under the corrected rule, the real 0.31.0 entry would fail with 29 undeprecated removals and
  0.27.1 the patch rule; `release-check` judges only the tag it is given.

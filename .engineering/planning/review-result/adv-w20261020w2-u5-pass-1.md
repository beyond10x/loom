## 5. Attacked and could not break
These ran as delegated probes, all green on fbea187. They are not committed, because the brief asks for failing tests only; they are kept in `adv/adversary_w20261020w2_u5.with-probes.rs`.
- **Host reached by name:** the child reached `model.example.test` by that name. Another name, and `127.0.0.2` on the same port, were refused.
- **Pinned address dialled directly:** with the aperture port different from the pinned port, dialling the pinned address was refused. Only the aperture reached the host.
- **Timeout:** an egress child blocked on its aperture came back as a timed-out result with no exit code, and `applied.network` named the aperture.
- **Shared driver key:** the aperture is part of the key. Egress, then plain, then egress again in one directory, and a plain child running beside an egress child, each got the right network.
- **By reading only:** the record checks refuse a wider or different network. `EgressAperture` and `with_egress` resolve through `loom_sdk` (`lib.rs:60-67,79`); I did not compile an sdk test for this.
- **Not tested:** the refusal for an aperture the driver does not publish. On this machine the mechanism proves itself, so I could not build that state.

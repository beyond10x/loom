**5. Attacked, could not break** (probes green, not committed; copy at `adv/adversary_p2_with_probes.rs`)
- **Refusals with a kept document:** a failing store gives `GovernorUnavailable` and a case the store no longer holds gives `UnknownCase`, both as `frontier` does.
- **The lock:** reading `decision_document` again from inside an evaluation's time callback, through `decision_document`, `frontier` and `completion`, does not deadlock. By reading, the lock is taken only in `kept_for` and `keep`.
- **The keep's match:** `CaseState` compares every field (`lib.rs:174`). The state only grows and the revision only goes up, so an old state cannot come back and match a stale document.
- **What `completion` keeps versus `frontier`:** both keep the same rendering of the same state. `frontier` keeps it only after `project` succeeds, but Canon 0.6.0 never produces a decision `project` refuses.
- **A failing time with a kept document:** `decision_document` returns the kept document while `frontier` refuses. The method's doc says exactly this, so it is not a finding.

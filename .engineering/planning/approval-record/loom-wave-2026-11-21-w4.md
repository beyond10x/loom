release (0.86.0 to 0.96.0) in a release, and a release (0.58.0) is being prepared, held for the
operator's own word. Session `sdc` decided: the move goes first as a one-unit wave if it is pin
and regeneration only, and this wave goes first on 0.86.0 if the move needs hand changes or a
decision. A probe in the managed tree `loom-ess096-probe` (uncommitted) found that under 0.96.0
the Commission system's gate and conformance refuse `HoldSuspension` in three places. So this
wave runs first, on 0.86.0.

  either. Pass 1: a `local` run was printed as `confinement: none` in the slice's run line and in

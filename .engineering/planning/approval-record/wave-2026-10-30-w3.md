## Decisions taken inside the item

1. Resources: a `Command` resource must declare its resources or the controller configuration must
   set a new `defaultCommandResources`, else `ResourcesRequired` (reasons in the story). Breaking.
2. Keyed writes: always keyed, key = `cli::idempotency_key` of the admitted request; a host
   without `standing_grants` refuses the key and the invoker reports `Err`. Breaking for such
   hosts. Alternative not taken: resend once unkeyed on that pre-dispatch refusal (it breaks
   Loom's "never resends").
3. C5: Loom's part is a host-named stable scratch copy path; metaharness's per-session child
   paths, b10x-harness's context order and the cache TTL class are the later metaharness item.
4. fsGroup (`crates/loom-operator/src/render.rs:944`) sets group modes aep's snapshot check
   rejects; aep fixes it on its side in a parallel wave; nothing changes here unless that wave asks.
5. ESS pin stays 0.77.0 (newest ESS release). metaharness stays 0.23.0 unless unit B needs more.

## How the batches run

This page replaces, for this run, the rule of one review per unit and one publication per wave:

- Five stories per batch, one implementation agent per story, each in its own managed worktree.
- Every unit merges into one integration branch, `wave/2026-11-21-w7`, which stays open; the
  batches are numbered w8, w9 and so on in the store's correlations.
- One review per batch, on the merged diff of the batch (security and adversary), then
  corrections on the integration branch, then the next batch.
- `main` is not published between batches. One pull request and one version at the end, when
  Runbook's driver has nothing left that Loom lacks.
- The test rule of `~/beyond10x/AGENTS.md` § "Tests stay fast" binds every unit.
